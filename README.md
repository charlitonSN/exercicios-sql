# SQL — Exercícios e Prática

## Sobre o projeto

Este repositório reúne minhas resoluções dos exercícios práticos do curso de SQL do canal [Teo Me Why](https://www.youtube.com/@teomewhy), com o objetivo de consolidar meus conhecimentos em SQL por meio da prática e do desenvolvimento do raciocínio lógico aplicado à análise de dados.

As atividades envolvem consultas a bancos de dados relacionais, manipulação de informações, agregações e exploração de dados para responder a perguntas de negócio.

Além de acompanhar o conteúdo do curso, procuro desenvolver minhas próprias soluções para os desafios propostos, documentando o processo de aprendizado e organizando os códigos para consulta futura.

## Conteúdos praticados

Ao longo dos exercícios, são explorados conceitos e comandos como:

- **Consultas:** `SELECT`, `DISTINCT`, `WHERE` e `ORDER BY`.
- **Filtros e condições:** `AND`, `OR`, `BETWEEN`, `IN` e `LIKE`.
- **Agregações:** `COUNT()`, `SUM()`, `AVG()`, `MIN()` e `MAX()`.
- **Agrupamentos:** `GROUP BY` e `HAVING`.
- **Relacionamento entre tabelas:** `INNER JOIN`, `LEFT JOIN` e outras operações de junção.
- **Estruturas condicionais:** `CASE WHEN`.
- **Funções de data e texto:** manipulação e extração de informações.
- **Análise temporal:** agrupamentos por mês e ano e comparação entre períodos.
- **Subconsultas e funções mais avançadas.**

## Ferramentas utilizadas

- **SQL:** linguagem utilizada para consultar e manipular bancos de dados.
- **SQLite:** sistema de gerenciamento de banco de dados relacional.
- **DB Browser for SQLite:** ferramenta utilizada para explorar os bancos de dados e executar consultas.

## Objetivos de aprendizagem

- Desenvolver autonomia na escrita de consultas SQL.
- Aprimorar o raciocínio lógico e a resolução de problemas.
- Aprender a relacionar e explorar dados de diferentes tabelas.
- Aplicar funções de agregação e manipulação de dados.
- Utilizar SQL para responder a perguntas de negócio.
- Construir uma base sólida para projetos de análise de dados.
